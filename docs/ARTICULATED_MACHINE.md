# Articulated machine implementation

The machine backend extends the shared Newton stepping path with a four-joint
serial articulation and effort-limited actuation. Joint commands are normalized
slew/boom/stick/bucket velocity requests in [-1, 1], scaled to 0.6 rad/s. Position
references integrate those requests within joint limits. A PD controller plus model
self-weight compensation requests motor effort, capped per joint and filtered by a
50 ms first-order response. Motor control runs each 2.5 ms physics tick independently
of the 20 ms policy period. This is an actuator approximation, not hydraulics.

The empty-machine comparison motivated using Featherstone for the machine while
retaining XPBD for the box-tool fixture. With the same three-second hold controller,
final boom error was approximately -0.161 rad for XPBD and -0.0079 rad for Featherstone.
This is development evidence, not a numerical convergence or physical tracking pass.
The gravity feedforward agreed with finite differences of gravitational potential at
the initial configuration (boom about -44.24 Nm, stick -20.04 Nm, bucket -2.26 Nm).

Version 2 of the procedural asset mounts the arm at x=-0.65 m to align the bucket
with the bed. It has an open top/front compound bucket rather than a convex hull.
Individual primitive masses/inertias are generated by Newton at the declared shape
density. Overlapping wall volumes contribute to that generated mass; no commercial
machine or measured bucket inertia is claimed. The base is fixed to the world.

## Material accounting under development

Instantaneous material inside the bucket cavity and above z=0.22 m is reported as
lifted bucket mass. A particle must meet that condition for at least 0.1 s of sampled
observations before it becomes eligible for deposit credit. Eligible particles count
as deposited only in |x| <= 0.25 m, 0.25 <= y <= 0.55 m, -0.04 <= z <= 0.15 m.
These are declared task geometry/accounting definitions, not physical tolerances.
Repeated diagnostic reads at the same physics tick do not advance particle history.

The earlier diagnostic counted all particles in the receiving region. A development
run exposed approximately 3.4 kg there from passive settling, before any lift. That
was an invalid productivity measure and was replaced. Those earlier local records
must not be used as successful excavation evidence.

Positive actuator work sums positive per-joint torque times angular velocity at
physics ticks. It excludes hydraulic efficiency and is an approximation to numerical
motor work. Soil force is action-averaged generated MPM force on the bucket; coupling
lag means it is not necessarily the same instantaneous impulse applied to the machine.

The first five-second coupled motion run completed, but did not establish a scoop.
Bucket retention, correct payload loads, dumping, repetition, resolution sensitivity,
and independent physical comparisons are still required.

## Domain correction

The preloaded free-bucket failure was resolved by enlarging the fixed-grid domain;
see [DOMAIN_CHECK.md](DOMAIN_CHECK.md). The constrained bucket carried a preload,
but excavation attempts still have not demonstrated successful pickup and deposit.
Static preload checks at 0.04 and 0.02 m voxels both retained all 0.384 kg for one
second. Those controls isolate useful mechanisms; they do not validate excavation.
